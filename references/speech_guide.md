# 演讲稿写作规范

配合 `scripts/count_speech.py` 使用。讲稿是一个 UTF-8 文本文件（markdown 风格），逐页撰写，默认目标 8 分钟。

## 文件格式

- 每页一段，以 `# 第 N 页 · 标题` 之类的标题行开头
- 统计字数时不计入：以 `#` 开头的行、单独的 `---` 分隔线、以 `论文：`、`时长：`、`说明：` 开头的行
- 文首可以写头部信息，例如：

```
# 演讲稿

论文：Attention Is All You Need
时长：8 分钟
说明：面向组会汇报，语速按 260 字/分钟

---

# 第 1 页 · 封面

各位老师同学好，今天我分享的是……
```

## 时长控制

- 语速按 260 到 270 汉字/分钟估计
- 8 分钟对应 2080 到 2160 汉字，其他时长按比例换算
- 写完后执行：

```bash
python3 scripts/count_speech.py 讲稿.md
python3 scripts/count_speech.py 讲稿.md --target 10
```

脚本输出汉字数与预计时长区间；低于目标下限会提示补充到建议字数，高于上限会提示压缩。

## 写作要求

- 逐页撰写：封面、提纲、每个分节页、每张内容页、致谢页各一段
- 分节页一句过渡即可；内容页按幻灯片要点的顺序展开，不要照读幻灯片
- 只讲论文给出的内容，不补写论文没有的结论；数值、指标名称、实验设置与论文一致
- 公式与符号使用与幻灯片相同的 Unicode 写法（例如 `α`、`N̂`、`R₁`）
